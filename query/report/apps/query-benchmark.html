Query benchmark

How long each tool takes to run a query and deliver its whole result, on one of two paths. Compare tools only within one.
File: CLI tools (psql, usql, anfra CLI) each write the whole result to a CSV file with a header row, timed from start to exit. HTTP: each tool answers the request its own frontend sends (anfra: streamed NDJSON; Superset: one JSON document), timed until the answer is read and parsed.

Compare tools

Pick the tools to compare. The first is the baseline; every other tool is a bar against it, per case. A bar left of 1× is faster than the baseline, right of it slower; its label says by how much. The scale is linear: a bar twice as long is twice as far from the baseline.

Case preview

What a case runs, and the first rows of what it returns: its columns of bench_wide's first rows, as psql writes them to CSV. Every case scans bench_wide with a LIMIT and no ORDER BY, which returns these rows first.

A run counts only when its result had the rows and columns its case expects; failed runs are flagged, and left out of the times. Cases: narrow is 3 columns, medium 10, wide 30; the suffix is the rows. See the benchmark's README for the method.
